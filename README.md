# D7046E_SNN_Project
Repo for the SNN project of the LTU course D7046E Neural Networks and Learning Machines.

## Initial goal  

We start simple, try to classify linear motion as left or right.

## SNN Framework(s) 

We will use the Brian2 Python module.

## Learning method(s)  

We will attempt to train the network using local (Hebbian) learning, STDP. 

## Input data generation 

We can begin training the network using spikes from the spike generator provided in the SNN3 exercise (Part 2, preparatory task).

## Code sharing

Code is shared in this GitHub repository. Each member can work in their own branch and we can discuss what to merge into main.
